H1

A tag H1 cria um título grande e chamativo, essa tag é possivel utilizar essa tag em ordem decrescente, por exemplo utilizar a tag "H2" para que seja um título ainda, mas com um tamanho menor do que o "H1".

P

A tag "p" é utilizada para criar parágrafos

HREF

A tag "HREF" possui a função de definir um texto "clicável" na qual o usuário tem a opção de clicar nele e ser direcionado para um local específico Você pode fazer com que ele seja direcionado para um website/link utilizando "a href="link"Texto-Personalizado a",também é possível você colocar uma característica para que o usuário seja redirecionado para o seu link, mas em uma guia você precisa fazer "a href="link" target="_blank""textoPersonalizado "a" caso você queria direcionar ele para alguma parte da sua própria página, você pode fazer assim: "a href="#comeco"CliqueAquiParaVoltarAoComeço a" e ai no local que você quer que ele volte você teria que adicionar o id "comeco" a tag no local que você quer que ele volte.

Body

A tag "Body" é um elemento crucial para a estrutura do HTML, pois é dentro de toda a tag do BODY que estará tudo que irá aparecer na tela do seu site.

HR

A tag HR cria uma linha separatória na sua página, como você pode ver é a mesma linha que está separando visualmente cada tag nesta página.
